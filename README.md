# 聚光灯 IP 孵化基地

可操作的 Three.js 三维空间。房间布局以最终确认概念图和用户逐次批注为准。概念图保存在 `public/assets/approved-concept.png`。

```sh
npm install
npm run dev -- --port 5173
```

访问 http://localhost:5173 。`npm run build` 构建静态发布目录 `dist/`。

## 操作
- WASD / 方向键：按当前视角移动；墙与主要家具有碰撞。
- 点击地面：自动寻路；点击区域标签或「基地全览」中的名称：自动走到功能位并开始互动。
- E：开始 / 结束附近区域互动；走路也会结束动作。
- 鼠标拖拽：旋转；滚轮：缩放；右键拖拽：平移；左上按钮重置视角。
- 手机提供屏幕方向键，可收起业务面板。

## 场景动作
活动区讲课、窗景口播、企划室坐下洽谈、三个直播间举商品和招呼观众、摄影棚操作相机、选品墙前取物展示。动作使用关节层级实时驱动；真实声音仅来自基地实拍视频。

## 业务资料
功能文案依据《文字记录：IP孵化基地相关内容讨论 2026年10月18日》。基地实拍视频由 IMG_9834.MOV 转码，保留原素材音轨。界面不把基地导览称为客户案例。

## 代码
- `src/world.js` / `props.js`：空间、家具、灯光和陈列。
- `src/avatar.js`：人物关节、行走与六类动作。
- `src/navigation.js`：碰撞与 A* 路径规划。
- `src/engine.js`：镜头、渲染、输入与互动。
- `src/data.js`：业务资料与互动点坐标。
- `src/main.jsx` / `style.css`：中文界面和响应式布局。

## 验证
`node scripts/verify.mjs` 在本机 Google Chrome 无头模式检查全部八个区域、视频播放、键盘移动和手机视口；先启动开发服务器。结果写入 `review/verification.json`。

这是实时三维第一版。人物为程序建模的可动画角色，尚未达到人物参考图的精确肖像还原；材质和实时光照与电影级概念图仍有差距。原始视频和照片不随意外传，当前仅在本机预览。
